Halo Mega Bloks (Project Haggar) decompilation and native port

Decompilation and native PC port of Project Haggar, the cancelled Halo Mega Bloks game (n-Space, Xbox 360, Unreal Engine 3). Also spelled Halo Mega Blocks.

Project Haggar is the Halo Mega Bloks game (also spelled "Halo Mega Blocks") that n-Space developed for the Xbox 360 on Unreal Engine 3 (the UDK July 2012 BETA 2 engine) until 343 Industries cancelled it in 2013. This open-source project rebuilds a development build of it from source, so it can run natively on PC and, eventually, on an Anbernic handheld.

Source code on GitHub · Start here · Progress · Active claims

Three tracks

  • Native port. A static recompilation of the whole Xbox 360 executable (the ReXGlue SDK) plus its runtime, which is Xenia's kernel, GPU and audio without the JIT. Later, a native renderer for handhelds.
  • n-Space's C++. A byte-matching decompilation with the original compiler (XDK 21076, cl 16.00.11886) and the build's own flags. Epic's engine is recompiled, not hand-decompiled.
  • UnrealScript. The game's script classes, decompiled from its cooked packages.

Can I play the cancelled Halo Mega Bloks game?

On Windows, yes, with your own copy of the build's files: build the port with PORTING.md. It reaches the first level, with the development build's own known issues. The repository contains no game files and no SDK files.
